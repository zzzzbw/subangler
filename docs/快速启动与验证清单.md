# SubAngler 快速启动与功能验证清单

> 用途：本地或 NAS 启动服务后，按本清单逐项亲自操作验证。  
> 适用版本：M3（Web UI 七页 + 单端口托管）。验证环境：Windows 本地 / Docker NAS。

---

## 一、快速启动

### 方式 A：本地直接运行（推荐用于本次验证）

在 `D:\ai\sub-angler` 目录打开 Git Bash：

```bash
cd D:/ai/sub-angler

# 首次启动需设置管理员账号密码（仅首次生效，之后以数据库为准）
export ADMIN_USERNAME=admin
export ADMIN_PASSWORD='Verify@2026'

# 启动服务（前台运行，日志直接可见；默认监听 0.0.0.0:8765）
.venv/Scripts/python.exe -m subangler.main
```

浏览器打开：**<http://127.0.0.1:8765>**

- 默认数据库：`config/subangler.db`，密钥：`config/secret.key`（首次自动生成）
- 若 8765 端口被占用：`export SUBANGLER_PORT=8790` 后重启，访问对应端口
- 停止服务：在运行窗口按 `Ctrl + C`

> 若希望使用一个干净的验证库（不污染已有数据），启动前追加：  
> `export SUBANGLER_DB_PATH="D:/ai/sub-angler/verify.db"`

### 方式 B：Docker / NAS 部署

```bash
cd D:/ai/sub-angler
cp .env.example .env
# 编辑 .env：设置 ADMIN_PASSWORD、MEDIA_ROOT（NAS 媒体库路径）、PUID/PGID
MEDIA_ROOT=/volume1/tvshows docker compose up -d --build
```

访问 `http://<NAS-IP>:8765`。媒体库目录挂载为只读之外的 `rw`（字幕需回写同目录），PUID/PGID 需与 NAS 媒体文件属主一致。

### 登录凭证

| 项   | 值                                                          |
| --- | ---------------------------------------------------------- |
| 用户名 | `admin`（或你设置的 `ADMIN_USERNAME`）                            |
| 密码  | 首次启动你设置的 `ADMIN_PASSWORD`；未设置则为 `change-me-on-first-login` |
| 改密码 | 登录后 → 设置页 → 「修改密码」卡片                                       |

服务健康检查（免登录）：`curl http://127.0.0.1:8765/api/health` 应返回 `{"ok":true,...}`。

## 三、常见问题

| 现象          | 排查                                                                    |
| ----------- | --------------------------------------------------------------------- |
| 打不开页面       | 确认服务在运行、端口正确（默认 8765）；`curl http://127.0.0.1:8765/api/health` 是否返回 ok |
| 忘记首次密码      | 未改过则默认 `change-me-on-first-login`；已改则删库重建会清数据，谨慎                      |
| 扫描不到视频      | 路径填的是容器内路径（Docker）还是本地绝对路径（本地运行）；目录是否含常见视频扩展名                         |
| 下载不到字幕      | 多为外部原因：未配置源凭证、OST 匿名配额耗尽、目标剧集无匹配候选；看任务「决策日志」定位                        |
| 系统自检一直「加载中」 | 属历史 bug，已修复；若仍出现请检查 `/api/health/full` 是否返回 200                       |
| 上传字幕报错      | 确认文件扩展名为 `.srt/.ass/.ssa/.vtt/.sub` 且 ≤20MB；已修复表单字段契约问题               |
